# Файл загрузки материалов

Ссылки компетенции: ИТС, обучение или видео. Загрузка — у админа на `/admin/competencies`, форма «Загрузка материалов». Книгу собирает команда ниже.

Файл книги в git не класть.

## Команда

Из корня репозитория. JSON — массив или объект с полем `materials`. `kind` — `its`, `training` или `video`.

```
npm run materials:xlsx -- tmp/materials.json tmp/materials.xlsx
```

При ошибке разбора файл не создаётся. В книгу вид пишется словами: ИТС, Обучение, Видео.

## Колонки

`Компетенция`, `Вид`, `Название`, `Адрес`.

Идентификатор компетенции, не название. Вид в файле: ИТС, обучение, видео либо `its`, `training`, `video`. Адрес только `http://` или `https://`.

Один и тот же адрес у одной компетенции повторно не добавляется. Если название или вид другие, ссылка обновляется. Ошибка в любой строке отменяет запись всего файла: пустая компетенция, неизвестный идентификатор, пустое название, чужой вид, адрес не http(s), у одного адреса разные название или вид.

Обязанность и корень дерева ссылку принимают: материал не задание справочника.
