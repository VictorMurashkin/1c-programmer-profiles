# База заданий и материалов

Находки по старым книгам ИПР и правки, без которых эту базу нельзя загрузить. Сами задания и ссылки в git не входят.

## Что в старых файлах

Книга ИПР — три листа: «Введение», «Инструкция», «План». План — список курсов и домашних заданий на переход между должностями, не справочник компетенций. Колонки: задача, статус, дата начала, плановые и фактические минуты. Уровень 1/2/3 там не задан.

Ссылки в старых книгах висят на ячейках задач. В базу брались только полные адреса http(s). Адрес без пути не использовался.

Обязанность в справочник заданий не ставится: загрузка и карточка это запрещают. У корней дерева (`group-*`) своих заданий нет, материалы есть. У профессиональной и универсальной компетенции — задания уровней 1, 2 и 3; у широких тем заданий больше одного.

## Правка загрузки

В книгу добавлена необязательная колонка «Уровень». Значения 1, 2 или 3 пишутся в справочник, в том числе при повторной загрузке. Пустая ячейка и файл без этой колонки уже заданный уровень не меняют. Новое задание без уровня по-прежнему не попадает в план, пока уровень не задан.

Материалы пакетом этой загрузкой не пишутся: ссылку по-прежнему добавляют на карточке компетенции. Список для отдельной загрузки хранит поля `competencyId`, `kind` (`its`, `training`, `video`), `title`, `url`.

Собрано 161 задание на 44 компетенции и 174 ссылки на все 85 компетенций, включая обязанности и корни дерева. У каждой компетенции есть уровни 1, 2 и 3. У частых тем заданий больше: язык 1С и запросы — по шесть, формы, СКД, расширения, типовые, хранилище, права, тесты и обмен — по пять, плюс отдельные задания у платформы, стандартов, HTTP, производительности запросов, блокировок, регистров и EDT.

В каждом тесте не меньше 10 вопросов. У перечисленных частых тем их 12 или 15. Книга на 5796 строк вариантов проходит тот же разбор, что и загрузка. Отдельного предела на число вопросов в приложении нет: сдача по-прежнему требует верный ответ на каждый вопрос.

Книгу заданий собирает `npm run assignments:xlsx`. Готовый xlsx в git не класть.
