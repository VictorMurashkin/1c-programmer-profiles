# Пометку вне текущего профиля можно править, пока строка есть

Сотрудник отмечает навык, потом меняется должность или закрывается ИПР, и навыка больше нет в наборе из ADR 0007. Истории должностей в справочнике нет, поэтому восстановить «все навыки прошлых грейдов» нельзя. Прятать такую строку или оставлять её только для чтения обрывает заметку, которую человек уже вёл. Помечать любой прошлый навык без строки тоже нельзя: не из чего понять, что он когда-то был его.

Уже стоящую пометку сотрудник видит и меняет: статус и пояснение. Новую пометку на навык вне текущей должности и цели активного ИПР поставить нельзя. «Не отмечено» стирает строку; вернуть навык можно, когда он снова войдёт в этот набор. В сводку «Мои компетенции» такие пометки не входят: она считает только текущий набор. Критерия у них нет: пометка не запоминает должность, а ожидание на разных грейдах разное.
