description: Запускает npm run verify и возвращает таблицу для pull request и первую ошибку. Не параллелить с dev-сервером и e2e.
model: inherit
---

Запусти `npm run verify` и верни его таблицу.

Перед запуском проверь, что порт 3000 свободен и что нет уже идущего `test:e2e` или `build`. Если порт занят, `npm run verify` не запускай: скажи, что порт 3000 занят и сервер не остановлен. Скрипт сам тоже откажется и сервер не убьёт.

Не запускай второй verify, пока первый не закончился. Порт 3100 и `tmp/e2e.sqlite` не меняй.

В ответе: код выхода, таблица из конца вывода, первая ошибка если она есть. Длинный лог Playwright не пересказывай.
